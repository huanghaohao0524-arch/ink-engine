# 书架首页设计

## 目标

把首页从“文件夹管理器”改成“我的书架”。用户进入软件后先看见书，而不是目录、章节和工具堆叠。

## 设计原则

- 首页只承担三件事：看见书、筛选书、进入书。
- 平台不再重复显示在书卡中，平台属于更上层分架。
- 题材作为首页主分组，左侧常驻。
- 章节树下沉到书内页，首页不展示 `书 > 卷 > 章`。
- 书卡保持轻量，只显示书名、卷章数、状态、最近更新。

## 布局

首页采用两栏结构：

- 左侧：题材栏，固定常驻，包含预置题材和用户自定义题材。
- 右侧：当前题材下的书卡网格。

书卡排序规则：

- 手动置顶优先。
- 其余按最近更新排序。

## 当前落地策略

当前源码层处于恢复期，正式 React 源码暂不可直接承接全部历史逻辑。第一版先采用可逆的书架增强层：

- 不破坏已有 `legacy-runtime.js` 写作链路。
- 通过 DOM 增强和 CSS 重塑首页书架。
- 后续确认方向后，再回迁为正式 React 组件。

## 验收标准

- 首页视觉不再像文件夹列表。
- 书卡比原来更轻，不展示平台和章节树。
- 左侧题材栏常驻，能切换题材视图。
- 写作、进入书籍、新建书籍等原有核心入口不被破坏。
